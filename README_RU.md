Библиотека для высокоточной десятичной арифметики на языке C (стандарт С11).

## Описание

Реализация собственного типа данных `decimal` для финансовых вычислений без ошибок округления, свойственных типам с плавающей точкой. Разработана в рамках учебной программы **Школы 21 (School21)**.

## Особенности

- **128-битное представление**: 96-битное целое число + коэффицент масштабирования
- **Точная арифметика**: сложение, вычитание, умножение, деление
- **Полный набор операторов сравнения**: <, >, <=, >=, ==, !=
- **Конвертация типов**: decimal <--> int <--> float
- **Математические функции**: floor, round, truncate, negate
- **Банковское округление**: соответствует финансовым стандартам
- **Диапазон значений**: в decimal можно хранить любое число от отриц. (79e28) -79 228 162 514 264 337 593 543 950 335 до положит. (79e28) +79 228 162 514 264 337 593 543 950 335
- **Безопасная работа с памятью**: отсутствие утечек

## Реализованные функции

### Арифметические операции

- `s21_add` - сложение
- `s21_sub` - вычитание
- `s21_mul` - умножение
- `s21_div` - деление

**Коды возврата:**

- 0 - OK
- 1 - число слишком велико или равно бесконечности
- 2 - число слишком мало или равно отрицательной бесконечности
- 3 - деление на 0

### Операторы сравнения

- `s21_is_less` - меньше (<)
- `s21_is_greater` - больше (>)
- `s21_is_equal` - равно (==)
- `s21_is_not_equal` - не равно (!=)
- `s21_is_less_or_equal` - меньше или равно (<=)
- `s21_is_greater_or_equal` - больше или равно (>=)

**Возвращаемое значение:** 0 - FALSE, 1 - TRUE

### Конверторы

- `s21_from_int_to_decimal` - int -> decimal
- `s21_from_float_to_decimal` - float -> decimal
- `s21_from_decimal_to_int` - decimal -> int
- `s21_from_decimal_to_float` - decimal -> float

**Коды возврата:** 0 - OK, 1 - ошибка конвертации

### Дополнительные функции

- `s21_floor` - округление вниз
- `s21_round` - округление до ближайшего целого
- `s21_truncate` - отбрасывание дробной части
- `s21_negate` -  смена знака

**Коды возврата:** 0 - OK, 1 - ошибка вычисления

## Тестирование

- Все арифметические операции с краевыми случаями

- Корректность операторов сравнения
- Обработку специальных значений и ошибок
